# HH Job Bot — поиск работы на hh.ru через Telegram

Личный Telegram-бот для поиска вакансий на hh.ru под свои параметры.
Бот спрашивает город, должность, желаемый доход, опыт, график и рабочие часы,
затем ищет вакансии в фоне и присылает их пачками по 10 штук.

> ⚠️ Бот **принципиально не ищет** вакансии, связанные с IT и программированием,
> а также курьеров, водителей, грузчиков, логистов, диспетчеров, машинистов,
> трактористов, автослесарей и похожие профессии. Фильтр работает по
> категории/роли на hh.ru, по названию вакансии и по введённому запросу.
> Дополнительно у каждого пользователя есть свой **чёрный список** слов.

## Что умеет

- Опрос из 6 шагов: город → должность/ключевые слова → доход → опыт → график → рабочие часы.
- Кнопка «Все профессии», если должность не важна.
- Фоновый поиск с остановкой после каждых 10 вакансий:
  «Продолжить (ещё 10)» или «Остановить».
- Карточка вакансии: название, область, диапазон ЗП, график, рабочие часы,
  опыт, контакты, прямая ссылка на hh.ru.
- Избранное: вакансии листаются стрелками в одном сообщении, кнопка «Удалить».
- Чёрный список: свои должности/ключевые слова, вакансии с ними не показываются;
  слова можно добавлять и удалять.
- `/start` в любой момент сбрасывает параметры и запускает опрос заново.

## Установка

Нужен Python 3.11+ (проверено на 3.13).

> Если в вашей сети Telegram API недоступен напрямую, укажите в `.env`
> `PROXY_URL` — например `http://127.0.0.1:10809` (HTTP-прокси)
> или `socks5://127.0.0.1:10808`. Для SOCKS нужен пакет `aiohttp-socks`
> (`pip install aiohttp-socks`).

```bash
cd hh-job-bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и вставьте токен бота:

```env
BOT_TOKEN=123456789:AA...
```

Токен выдаёт [@BotFather](https://t.me/BotFather) командой `/newbot`.

Запуск:

```bash
python bot.py
```

Или двойным кликом по `run.bat` на Windows.

## Деплой на сервер

Репозиторий приватный. На сервере либо выполните `gh auth login`, либо используйте
personal access token / deploy key, чтобы `git clone` имел доступ.

### Вариант 1: Docker (рекомендуется)

```bash
git clone https://github.com/Aueueaueueaae/dreamjob-bot.git
cd dreamjob-bot
cp .env.example .env
nano .env   # вставьте BOT_TOKEN, при необходимости PROXY_URL
mkdir -p data
docker compose up -d --build
docker compose logs -f
```

База `data/bot.sqlite3` хранится на хосте в папке `data/`, поэтому избранное
и чёрный список не пропадут при пересоздании контейнера.

Остановить / обновить:

```bash
docker compose down
git pull
docker compose up -d --build
```

### Вариант 2: systemd (без Docker)

```bash
sudo apt update
sudo apt install -y python3-venv git nano
sudo useradd -r -m -d /opt/dreamjob-bot -s /bin/false bot

sudo git clone https://github.com/Aueueaueueaae/dreamjob-bot.git /opt/dreamjob-bot
sudo chown -R bot:bot /opt/dreamjob-bot
sudo -u bot python3 -m venv /opt/dreamjob-bot/.venv
sudo -u bot /opt/dreamjob-bot/.venv/bin/pip install -r /opt/dreamjob-bot/requirements.txt

sudo -u bot cp /opt/dreamjob-bot/.env.example /opt/dreamjob-bot/.env
sudo -u bot nano /opt/dreamjob-bot/.env   # BOT_TOKEN и остальное

sudo cp /opt/dreamjob-bot/deploy/dreamjob-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now dreamjob-bot
sudo systemctl status dreamjob-bot
sudo journalctl -u dreamjob-bot -f
```

Если пользователь/путь другие — поправьте `User`, `WorkingDirectory`,
`EnvironmentFile` и `ExecStart` в `deploy/dreamjob-bot.service`.

### Важно для сервера

- Telegram API на некоторых хостингах может быть недоступен — тогда задайте
  `PROXY_URL` в `.env`.
- hh.ru может показывать капчу для IP дата-центров. Если поиск перестанет
  работать сразу после деплоя — скорее всего, хостинг попал под антибот.
  В этом случае лучше российский VPS или другая сеть.
- Не коммитьте `.env`: он уже в `.gitignore` и `.dockerignore`.
- Если хотите перенести избранное и чёрный список с домашнего ПК — скопируйте
  `data/bot.sqlite3` в `data/` на сервере до первого запуска.

## Настройки `.env`

| Переменная | Обязательно | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен бота от @BotFather |
| `OWNER_ID` | нет | Ваш Telegram ID. Если указан, бот отвечает только вам |
| `PROXY_URL` | нет | Прокси для Telegram API, если он недоступен напрямую |
| `HH_TOKEN` | нет | OAuth-токен hh.ru — нужен только для показа контактов работодателя |
| `BATCH_SIZE` | нет | Сколько вакансий присылать до паузы (по умолчанию 10) |
| `MESSAGE_DELAY` | нет | Пауза между сообщениями, сек (по умолчанию 1.4) |
| `PAGE_DELAY` | нет | Пауза между страницами hh.ru, сек (по умолчанию 1.0) |
| `MAX_PAGES` | нет | Максимум страниц за запуск (1 страница = до 50 вакансий) |

`OWNER_ID` можно узнать у [@userinfobot](https://t.me/userinfobot).
Также можно отправить боту команду `/id` — он покажет ваш ID.

## Команды бота

- `/start` — заново собрать параметры (сбрасывает текущий поиск).
- `/search` — начать поиск с сохранёнными параметрами.
- `/favorites` — избранные вакансии.
- `/blacklist` — чёрный список слов и должностей.
- `/stop` — остановить поиск.
- `/menu` — главное меню.
- `/help` — справка.

## Как работает поиск

1. Бот собирает фильтры и сохраняет их в `data/bot.sqlite3`.
2. По кнопке «Начать поиск» запускается фоновая задача.
3. Бот листает выдачу hh.ru (сортировка — сначала новые), отбрасывает:
   - вакансии из категории «Информационные технологии»;
   - вакансии с IT-названиями (`программист`, `разработчик`, `devops`, `python` и т. п.);
   - курьеров, водителей, экспедиторов, таксистов, дальнобойщиков;
   - машинистов, трактористов, автослесарей, логистов, диспетчеров,
     менеджеров по доставке;
   - грузчиков, комплектовщиков, сборщиков заказов, погрузку/разгрузку
     (по названию и ролям hh.ru);
   - вакансии, в названии которых есть слово из **вашего чёрного списка**;
   - вакансии с зарплатой ниже желаемой (вакансии без указанной ЗП сохраняются).
4. Каждые 10 вакансий бот останавливается и показывает меню продолжения.
5. Поиск никогда не работает «вечно»: максимум `MAX_PAGES` страниц за запуск.

## Чёрный список

Раздел «🚫 Чёрный список» в меню (или команда `/blacklist`):

- «➕ Добавить слово» — введите название должности или ключевое слово;
- совпадения ищутся по названию вакансии без учёта регистра, `ё` приравнивается к `е`;
- «❌ слово» — удалить слово из списка;
- до 100 слов, показ по 10 на страницу.

Например, можно добавить `мойщик`, `уборщик`, `официант`, `стажер`, `senior`.
Если в названии вакансии встретится любое из этих слов, вакансия не будет показана.
Изменения сразу учитываются при следующем запуске поиска или продолжении пачки.

## Про парсинг hh.ru

Официальный API поиска hh.ru (`api.hh.ru/vacancies`) сейчас отдаёт `403` без
авторизации и капчи, поэтому поиск идёт через HTML-страницу `hh.ru/search/vacancy`.
Из неё берётся встроенный JSON `HH-Lux-InitialState` — те же данные, что видит
браузер. Справочник городов — через открытый `api.hh.ru/suggests/areas`.

Если hh.ru покажет капчу, бот пришлёт сообщение и попросит подождать. Это
ограничение сайта, а не ошибка бота.

### Контакты

hh.ru скрывает контакты работодателя от анонимных посетителей. Бот показывает:
- реальные телефон/email, если они есть в данных вакансии;
- «указаны на странице вакансии» — если контакты есть, но скрыты;
- «не указаны» — если работодатель их не публиковал.

Чтобы получать контакты через API hh.ru, можно указать `HH_TOKEN` (OAuth-токен
соискателя). Без него бот всё равно работает, просто контакты будут видны только
по ссылке на hh.ru.


## Ограничения

- Это парсер, а не официальная интеграция: при изменении вёрстки hh.ru может
  потребоваться обновление `hh_client.py`.
- hh.ru может включать антибот при слишком частых запросах — не ставьте
  `MESSAGE_DELAY` и `PAGE_DELAY` в ноль.
- Вакансии без указанной зарплаты не отбрасываются по фильтру дохода,
  иначе бот терял бы большую часть рынка.
- IT-фильтр намеренно широкий: под него попадает вся категория
  «Информационные технологии» hh.ru, включая часть смежных ролей
  (продуктовые менеджеры, дизайнеры, аналитики).
- Глобальный фильтр исключает роли `Водитель, экспедитор` и `Курьер, Почтальон`,
  а также названия с «курьер», «водитель», «шофёр», «экспедитор», «таксист»,
  «дальнобойщик», «машинист», «тракторист», «автослесарь», «логист»,
  «диспетчер», «менеджер по доставке», «грузчик», «погруз», «разгруз»,
  «комплектовщик», «сборщик заказов».
- Чёрный список проверяет только название вакансии. Если слово встречается
  лишь в описании, вакансия не скрывается.
